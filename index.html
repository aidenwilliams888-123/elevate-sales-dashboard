Owner estimates

Calculated care metrics

5 × $50 = $250/month; $250 × 12 = $3,000 annualized. (2 × 5 + 2 × 4 + 1 × 3) × $50 = $1,050 scheduled charges under the stated tenure convention.

Missing details remain missing

Your data, your copy

No account, backend, or automatic CRM connection

The published page contains only the approved aggregate snapshot. Project entries and edits save locally in this browser; they do not update GitHub or anyone else’s dashboard.

Export a JSON backup before clearing browser storage. Import it on another device to continue. A backup replaces the local copy only after validation.

Keep client names and payment details out of public commits. The GitHub README explains how to publish an updated anonymous snapshot.

INTERVIEW NOTES

Explain what you built—and what the data supports.

“This browser dashboard separates my reported business totals from detailed records. The current care plans calculate to $250 per month. I left historical trends and exact conversion unavailable until I reconstruct the underlying records. The project ledger then calculates cash collections, average project value, and monthly trends from those entries.”

This is a browser dashboard, not Power BI. The repository includes SQL reconciliation and a Power BI data model guide for building a native version later. Describe only the tools and work you have actually used.
